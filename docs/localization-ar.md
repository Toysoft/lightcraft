# ‫LightCraft بالعربية

اختر **تحرير ← اللغة ← العربية** أو **الإعدادات ← عام ← اللغة**. يُطبَّق التغيير فوراً ويُحفظ
للجلسة التالية (يُخزَّن `language: "ar"` في `ui.json`). وتقبل `LIGHTCRAFT_LANGUAGE` أي صيغة عربية
(`ar`، `ar-SA`، `ar_EG.UTF-8`، `ar-001`…).

يغطي الفهرس العربي القوائم واختصارات لوحة المفاتيح والمكتبة والتطوير والقصّ والأقنعة
والاستيراد والتصدير والإعدادات والإعدادات المسبقة وملفات التعريف المدمجة والسجل والتواريخ
ورسائل التقدم — كل مفاتيح اتحاد اللغات الأخرى. كما في بقية اللغات، تبقى الأخطاء التقنية من
المستويات الدنيا بالإنجليزية، وتظهر النصوص غير الموجودة في الفهرس بالإنجليزية.

أسماء الملفات ومعرّفات الأوامر والقوالب والألبومات والإعدادات المسبقة والبيانات الوصفية ذات
الأسماء الخاصة لا تُترجَم. تُرسم واجهة LightCraft وفق ترتيب egui من اليسار إلى اليمين (لا
يوجد فيها تمرير ثنائي الاتجاه للنص بعد)، وتبقى صور الصور الفوتوغرافية وإحداثياتها كما هي.
تعمل الواجهة بخط Noto Sans Arabic من [storytold/craft-fonts](https://github.com/storytold/craft-fonts)
(مدمج في كل الإصدارات الرسمية عبر `CRAFT_FONTS_DIR`)؛ ومن دونه تظهر الحروف مربعات.

## المصطلحات

تُستخدم صيغة الأمر أو الأسلوب الشخصي في التعليمات («انقر…»، «اختر…»). مصطلحات تُبقى متسقة:

| الإنجليزية | العربية |
|---|---|
| Highlights / Shadows | الإضاءات / الظلال |
| Exposure | التعريض |
| White Balance | موازنة اللون الأبيض |
| Vibrance | الحيوية |
| Tint | الصبغة |
| Hue (HSL) | درجة اللون |
| Color Grading | تدرير الألوان |
| Preset | إعداد مسبق |
| Pick / Reject | منتقاة / مرفوضة |
| Upright | التقويم |
| Lens Corrections | تصحيحات العدسة |
| Clipping | القصّ اللوني |
| Stack | تجميع |
| Keyword | كلمة مفتاحية |
| Recently Deleted | المحذوفات الأخيرة |

تصحيحات الناطقين بالعربية موضع ترحيب: افتح issue أو pull request مع النص الإنجليزي والترجمة
الحالية والمقترح.

## الصيانة والتحقق

النصوص الثابتة: `crates/ui-egui/locales/ar.json`. الرسائل ذات القيم:
`crates/ui-egui/locales/ar-formats.json`. المفاتيح الإنجليزية لا تتغير؛ وتتحقق شبكة `format!`
من العلامات عند البناء. تُخفى لواحق الجمع الإنجليزية بـ `{:.0}` (كما في الأوكرانية).

```sh
cargo test -p lightcraft-ui-egui i18n::tests -- --nocapture
LIGHTCRAFT_LANGUAGE=ar lightcraft-cli snapshot --demo -o arabic.png --size 1600x1000
```
